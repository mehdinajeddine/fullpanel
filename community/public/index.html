01 / DÉPLOYER

Du code à l’application.

Déployez depuis un dépôt Git, une image Docker ou un Dockerfile. Connectez vos dépôts privés avec une clé SSH dédiée.

  • Clé publique à ajouter au dépôt
  • Historique et journaux de déploiement
  • Retour à une version applicative sauvegardée
02 / COMPRENDRE

Voyez ce qui se passe.

Consultez les états, les logs et les ressources de chaque service. Les mesures indiquent leur fraîcheur ; une donnée absente reste clairement signalée.

  • CPU, mémoire et compteurs réseau
  • Diagnostic des ports réellement à l’écoute
  • Domaines et configuration HTTPS
03 / CONSERVER

Vos données ont leur place.

Gérez vos services de bases de données. Planifiez des sauvegardes locales et restaurez-les vers un service compatible, avec une sauvegarde préalable.

PostgreSQLMySQLMariaDBMongoDBRedis
04 / COLLABORER

Le bon accès, par projet.

Organisez vos applications par projet et attribuez les permissions adaptées. Partagez des variables d’environnement et automatisez vos opérations via l’API.

  • Accès lecteur ou opérateur
  • Variables communes et surcharges par service
  • Clés API à portée limitée
En développement actif

FullPanel évolue encore. Consultez les capacités vérifiées et les limites actuelles avant de l’utiliser en production.

commence ici.

Installez FullPanel sur votre serveur Docker, puis créez votre espace de travail.

  1. 1

    Préparez votre serveur

    Docker Engine et le plugin Compose sont nécessaires pour l’installation.

  2. 2

    Installez FullPanel

    Clonez le dépôt et lancez le script d’installation fourni.

  3. 3

    Créez votre premier projet

    Créez le compte propriétaire, ajoutez votre source et déployez votre application.

Installation sur votre serveurshell
git clone https://github.com/mehdinajeddine/fullpanel.git
cd fullpanel
sh scripts/install.sh
À exécuter sur le serveur choisi

L’interface d’administration reste locale après l’installation. Le guide explique l’accès par tunnel SSH et la configuration des domaines.
